# Knowledge

Curated, public, committable reference material the assistant reads on demand.
One topic per file. Link sources and note their license; do not paste whole
copyrighted works. Personal notes go in `private/`, not here.

| File | Topic | Source |
|---|---|---|
| `skills.yaml` | skill vocabulary for parsing job posts | written for careerbrew |
| `topics.yaml` | starter question bank (coding, system design, behavioral) | written for careerbrew; curricula for further study: [tech-interview-handbook](https://github.com/yangshun/tech-interview-handbook) (MIT), [system-design-primer](https://github.com/donnemartin/system-design-primer) (CC BY-SA 4.0), NeetCode 150 topic list |
| `rubrics/*.yaml` | binary rubrics per round | written for careerbrew |
| `sources.yaml` | every public source careerbrew cites (id, title, url, kind) | generated by `scripts/import-research.py` |
| `strategy.yaml` | strategy rules and the research claims behind them | generated; each rule cites sources |
| `interview/steps.yaml` | 13 shared interview steps: description, what is evaluated, tips, traps, prep | generated from `research/interview-research.yaml` |
| `companies/*.yaml` | sourced interview loops for 5 sample companies (official pages first) | generated; checked by `scripts/check-sources.py` |
| `research/interview-research.yaml` | raw research with every URL opened (2026-10-18) | research agent; rerun `scripts/import-research.py` after edits |
| `research/interview-research-<batch>.yaml`, `research/ai-policy-research-<name>.yaml` | optional extra batches for companies you research yourself; their company files go to `companies-extra/` and their sources to `sources-extra.yaml` (tests and pictures read only the base set: `CAREERBREW_EXTRA_KNOWLEDGE=0`) | research agent; rerun `scripts/import-research.py` after edits |
| `research/api-notes.md` | job platform, mail, and calendar API notes and terms | research agent, 2026-10-18 |
| `cards/*.yaml` | the public study deck: interview questions with a short answer and a full explanation, one file per topic | generated by the `card-explainer` skill with `prompts/card-explainer.md`, written in our own words, checked by `careerbrew cards public-check` and `scripts/check-card-code.py` (every Python, JS/TS, JSON, and YAML example parses); never edit by hand, publish with `careerbrew cards publish` |
| `exercises/*.yaml` | 150 coding exercises in the classic pattern order (arrays and hashing to bit manipulation), each with an original statement, tests with edge-case notes, a scaling check, tiered hints, a lesson, and a reference solution | written for careerbrew (own words; the problem list follows the public NeetCode 150 roadmap order, with LeetCode slugs for sync: each file's `leetcode:` field names its source problem, `https://leetcode.com/problems/<slug>/`); every reference solution is checked by `careerbrew exercises check`, and each exercise was solved independently from its statement |
| `teaching.yaml` | how the teacher behaves (one step, retrieval first, spacing, hints, mistakes, tone, owner decides) and the signals it watches | written for careerbrew; rules cite `sources.yaml` ids |
| `ladders/generic-swe.yaml` | generic engineering ladder | written for careerbrew, shaped after public frameworks listed on [progression.fyi](https://progression.fyi) |
